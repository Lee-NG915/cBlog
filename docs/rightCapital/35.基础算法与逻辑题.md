# 二面基础算法与逻辑题速记

> 面试反馈：题目偏基础算法，不难，主要考察数学和逻辑思维。  
> 本文只记录核心思路、伪代码或简短 ES6 写法，不展开完整实现。

---

## 一、答题时的固定表达

1. 先确认输入、输出、数据范围和异常情况。
2. 先说最直观的方案，再说明能否优化。
3. 写代码前用一个例子手动推演。
4. 主动说明时间复杂度和空间复杂度。
5. 最后检查空输入、重复值、负数、溢出和边界下标。

```text
确认题意 → 暴力解法 → 找重复计算或额外空间 → 优化 → 示例验证 → 边界检查
```

## 二、数学与数字处理

### 1. 判断质数 ⭐

**题目：** 输入正整数 `n`，判断它是不是质数。

**核心思路：**

- 小于 `2` 不是质数。
- 如果 `n` 有大于 `sqrt(n)` 的因数，一定同时存在一个小于 `sqrt(n)` 的配对因数。
- 因此只需要检查到 `i * i <= n`。

```js
if (n < 2) return false;
for (let i = 2; i * i <= n; i++) {
  if (n % i === 0) return false;
}
return true;
```

时间复杂度：`O(√n)`；空间复杂度：`O(1)`。

---

### 2. 最大公约数与最小公倍数 ⭐

**核心思路：** 使用欧几里得算法，`gcd(a, b) = gcd(b, a % b)`。

```js
const gcd = (a, b) => {
  while (b !== 0) [a, b] = [b, a % b];
  return Math.abs(a);
};

const lcm = (a, b) => Math.abs((a / gcd(a, b)) * b);
```

先除后乘可以降低中间结果溢出的风险。

时间复杂度：`O(log(min(a, b)))`。

---

### 3. 整数反转

**核心思路：** 每次用 `% 10` 取最后一位，再用整数除法删除最后一位。

```text
result = result * 10 + n % 10
n = trunc(n / 10)
```

负数可以先保存符号，最后恢复。返回前检查结果是否超出题目规定的整数范围。

---

### 4. 不转字符串判断回文数 ⭐

**核心思路：** 只反转数字的后一半，避免完整反转产生溢出。

```text
负数，或末尾为 0 但数字不为 0 → false

reversedHalf = 0
while n > reversedHalf:
    reversedHalf = reversedHalf * 10 + n % 10
    n = floor(n / 10)

偶数位：n === reversedHalf
奇数位：n === floor(reversedHalf / 10)
```

---

### 5. 数字不断求各位之和

**基础思路：** 循环拆分数字，直到结果小于 `10`。

**数学优化：** 使用数字根。

```js
const digitalRoot = n => (n === 0 ? 0 : 1 + ((n - 1) % 9));
```

原因：十进制下 `10 ≡ 1 (mod 9)`，所以一个数与它的各位和模 `9` 同余。

---

### 6. 阶乘末尾有多少个零

**核心思路：** 一个零来自一个因子 `10 = 2 × 5`。阶乘中因子 `2` 更多，因此只需要统计因子 `5`。

```js
let count = 0;
for (let divisor = 5; divisor <= n; divisor *= 5) {
  count += Math.floor(n / divisor);
}
```

必须继续统计 `25、125...`，因为这些数字包含多个因子 `5`。

---

### 7. 不使用 Math.sqrt 求整数平方根 ⭐

**核心思路：** 在 `[0, n]` 中二分查找满足 `mid² <= n` 的最大整数。

```text
left = 0, right = n, answer = 0
while left <= right:
    mid = floor((left + right) / 2)
    if mid <= n / mid:
        answer = mid
        left = mid + 1
    else:
        right = mid - 1
```

使用 `mid <= n / mid` 可以避免 `mid * mid` 溢出。

时间复杂度：`O(log n)`。

---

### 8. 快乐数

**核心思路：** 不断计算各位数字的平方和。结果只有两种：到达 `1`，或者进入循环。

```js
const seen = new Set();
while (n !== 1 && !seen.has(n)) {
  seen.add(n);
  n = sumOfSquaredDigits(n);
}
return n === 1;
```

空间优化可以把数字变化看成链表，使用快慢指针检测循环。

## 三、数组与基础逻辑

### 9. 两数之和 ⭐

**核心思路：** 遍历时使用 `Map` 保存已经出现的数字及其下标。

```js
const seen = new Map();
for (let i = 0; i < nums.length; i++) {
  const targetValue = target - nums[i];
  if (seen.has(targetValue)) return [seen.get(targetValue), i];
  seen.set(nums[i], i);
}
```

时间复杂度：`O(n)`；空间复杂度：`O(n)`。

---

### 10. 找出 0～n 中缺失的数字 ⭐

**求和方案：**

```js
const expected = (n * (n + 1)) / 2;
return expected - nums.reduce((sum, value) => sum + value, 0);
```

**异或方案：**

```text
result = 0
把 0～n 和数组中所有数字全部异或
相同数字相互抵消，剩下的就是缺失值
```

异或不需要担心求和溢出，额外空间为 `O(1)`。

---

### 11. 只出现一次的数字 ⭐

**核心思路：** `a ^ a = 0`，`a ^ 0 = a`，异或满足交换律。

```js
return nums.reduce((result, value) => result ^ value, 0);
```

适用前提：除一个数字外，其他数字都恰好出现两次。

时间复杂度：`O(n)`；空间复杂度：`O(1)`。

---

### 12. 原地移动零到数组末尾 ⭐

**核心思路：** 双指针。`write` 指向下一个非零数字应该写入的位置。

```text
write = 0
for value of nums:
    if value !== 0:
        nums[write++] = value

write 之后的位置全部填 0
```

保留了非零元素的相对顺序。时间 `O(n)`，空间 `O(1)`。

---

### 13. 合并两个有序数组 ⭐

**核心思路：** 两个指针分别指向数组开头，每次取较小值。

```text
i = 0, j = 0
while 两边都有元素:
    push 较小值，并移动对应指针
把剩余元素追加到结果
```

如果第一个数组尾部预留了空间，可以从两个数组末尾开始写，避免覆盖未读取的数据。

时间复杂度：`O(m + n)`。

---

### 14. 不排序找第二大值

**核心思路：** 一次遍历维护 `largest` 和 `second`，并忽略与最大值重复的元素。

```text
value > largest:
    second = largest
    largest = value
else if largest > value > second:
    second = value
```

需要先确认题目要的是“第二大的不同值”，还是排序后第二个位置的值。

---

### 15. 多数元素

**核心思路：** Boyer-Moore 投票算法。不同数字相互抵消，超过一半的数字最终一定留下。

```js
let candidate;
let count = 0;
for (const value of nums) {
  if (count === 0) candidate = value;
  count += value === candidate ? 1 : -1;
}
return candidate;
```

如果题目不保证多数元素存在，需要再遍历一次验证出现次数。

时间 `O(n)`，空间 `O(1)`。

---

### 16. 两个数组的交集

**不保留重复：**

```js
const right = new Set(nums2);
return [...new Set(nums1)].filter(value => right.has(value));
```

**保留重复次数：** 使用 `Map` 记录一个数组中每个数字剩余的出现次数，匹配一次后减一。

## 四、字符串与括号

### 17. 有效括号 ⭐

**核心思路：** 遇到左括号入栈，遇到右括号时检查是否与栈顶配对。

```js
const pairs = new Map([
  [')', '('],
  [']', '['],
  ['}', '{'],
]);
```

```text
左括号 → push
右括号 → pop 必须等于 pairs.get(当前字符)
遍历结束后栈必须为空
```

时间 `O(n)`；空间 `O(n)`。

---

### 18. 第一个只出现一次的字符

**核心思路：** 第一次遍历计数，第二次按原顺序找计数为 `1` 的字符。

```js
const count = new Map();
for (const char of str) count.set(char, (count.get(char) ?? 0) + 1);
for (const char of str) if (count.get(char) === 1) return char;
```

`for...of` 按 Unicode Code Point 遍历，比按字符串下标更适合处理部分 Unicode 字符；完整 Grapheme Cluster 仍需要 `Intl.Segmenter`。

---

### 19. 判断字母异位词 ⭐

**排序方案：**

```js
const normalize = value => [...value].sort().join('');
return normalize(a) === normalize(b);
```

时间复杂度约为 `O(n log n)`。

**计数方案：** 用 `Map` 对第一个字符串加一，对第二个字符串减一，最后全部为零。时间 `O(n)`，空间取决于字符集大小。

---

### 20. 最长公共前缀

**核心思路：** 把第一个字符串作为前缀，依次与后续字符串比较；不匹配时不断缩短前缀。

```text
prefix = strings[0]
for current of strings:
    while current 不以 prefix 开头:
        删除 prefix 最后一个字符
```

也可以纵向逐列比较所有字符串的同一位置。

---

### 21. 压缩字符串

**核心思路：** 使用游标统计连续相同字符的长度。

```text
start = 0
while start < length:
    end 从 start 向后找到第一个不同字符
    写入 char + (end - start)
    start = end
```

如果题目要求“压缩后更长则返回原字符串”，生成结果后比较长度即可。

---

### 22. 解码字符串

**题目示例：** `3[a2[c]] → accaccacc`

**核心思路：** 使用两个栈分别保存进入 `[` 前的重复次数和已有字符串。

```text
数字 → 累积 repeat
"[" → repeat 和 current 入栈，然后重置
字母 → 追加到 current
"]" → previous + current.repeat(repeat)
```

嵌套结构必须按照后进先出的顺序处理。

---

## 五、查找与区间

### 23. 二分查找 ⭐

```js
let left = 0;
let right = nums.length - 1;

while (left <= right) {
  const mid = left + Math.floor((right - left) / 2);
  if (nums[mid] === target) return mid;
  if (nums[mid] < target) left = mid + 1;
  else right = mid - 1;
}
return -1;
```

关键是始终保持搜索区间定义一致，例如上面使用闭区间 `[left, right]`。

---

### 24. 有序数组的插入位置 ⭐

**核心思路：** 查找第一个“大于等于目标值”的位置，也就是 Lower Bound。

```text
区间使用 [left, right)
while left < right:
    mid = floor((left + right) / 2)
    nums[mid] < target → left = mid + 1
    否则 → right = mid
return left
```

即使目标值不存在，`left` 最终也是正确插入位置。

---

### 25. 不修改数组找重复数字

**条件：** 长度为 `n + 1`，元素范围为 `1～n`，只有一个重复数字。

**核心思路：** 把“下标指向对应数字”看成链表。重复数字会形成环，使用 Floyd 快慢指针：

```text
1. slow 每次走一步，fast 每次走两步，找到环内相遇点
2. slow 回到起点
3. 两个指针每次都走一步
4. 再次相遇的位置就是环入口，也就是重复数字
```

时间 `O(n)`；空间 `O(1)`；不修改原数组。

---

### 26. 合并重叠区间

**核心思路：**

1. 按区间起点排序。
2. 当前区间起点小于等于上一个结果区间的终点时合并。
3. 否则开启一个新区间。

```js
intervals.sort((a, b) => a[0] - b[0]);
```

排序占主要成本，时间复杂度为 `O(n log n)`。

---

### 27. 最大连续子数组和 ⭐

**核心思路：** Kadane 算法。当前位置的最佳结果，要么从当前数字重新开始，要么接在前面的连续子数组后面。

```js
let current = nums[0];
let best = nums[0];
for (let i = 1; i < nums.length; i++) {
  current = Math.max(nums[i], current + nums[i]);
  best = Math.max(best, current);
}
```

不要把初始值设为 `0`，否则无法正确处理全部为负数的数组。

时间 `O(n)`；空间 `O(1)`。

## 六、递归、回溯与组合

### 28. 斐波那契数列 ⭐

**问题：** 直接递归会重复计算相同子问题，时间复杂度接近 `O(2ⁿ)`。

**迭代方案：**

```js
let previous = 0;
let current = 1;
for (let i = 0; i < n; i++) {
  [previous, current] = [current, previous + current];
}
return previous;
```

时间 `O(n)`；空间 `O(1)`。

---

### 29. 爬楼梯 ⭐

**核心思路：** 到达第 `n` 级的最后一步，只可能来自 `n - 1` 或 `n - 2`：

```text
ways(n) = ways(n - 1) + ways(n - 2)
```

本质上是斐波那契数列。使用两个变量滚动保存前两项即可。

---

### 30. 数组扁平化

**ES6 方案：**

```js
array.flat(Infinity);
```

**递归思路：**

```text
遍历每个元素
如果是数组 → 递归展开
否则 → 放入结果
```

指定深度时，每次递归将 `depth - 1`，到 `0` 后停止展开。

---

### 31. 全排列

**核心思路：** 回溯。每一层选择一个尚未使用的数字，递归完成后撤销选择。

```text
backtrack(path):
    path.length === nums.length → 保存副本
    for 每个数字:
        已使用 → 跳过
        标记使用，加入 path
        backtrack(path)
        撤销 path 和使用标记
```

如果输入存在重复数字，需要先排序，并在同一层跳过重复选择。

---

### 32. 求所有子集

**迭代思路：** 初始只有空集。每遇到一个数字，把它加入现有每个子集，生成一批新子集。

```js
let result = [[]];
for (const value of nums) {
  result = [...result, ...result.map(group => [...group, value])];
}
```

共有 `2ⁿ` 个子集，因此时间和结果空间至少都是 `O(2ⁿ)`。

## 七、口头数学与逻辑题

### 33. 三个开关与一盏灯 ⭐

**核心思路：** 除了灯的亮灭，还可以利用灯泡温度携带第二种信息。

```text
打开开关 A 一段时间后关闭
打开开关 B
进入房间：
亮着 → B
熄灭但温热 → A
熄灭且冷 → C
```

---

### 34. 八个球找出较重的球 ⭐

**核心思路：** 第一次把球分为 `3、3、2`。

```text
称 3 对 3：
平衡 → 重球在剩余 2 个中，再称一次
不平衡 → 重球在较重的 3 个中，取其中 2 个互称
```

最少两次。每次天平称重有三种结果，因此两次最多区分 `3² = 9` 种情况。

---

### 35. 两根燃烧不均匀的绳子计算 45 分钟

**核心思路：**

```text
绳 A 两端同时点燃，绳 B 点燃一端
绳 A 在 30 分钟后烧完
此时点燃绳 B 的另一端
绳 B 剩余部分再过 15 分钟烧完
合计 45 分钟
```

虽然燃烧速度不均匀，但两端同时燃烧会把总时间减半。

---

### 36. 使用 3 升杯和 5 升杯得到 4 升水

**一种思路：**

```text
装满 5 升杯 → 倒入 3 升杯，5 升杯剩 2 升
清空 3 升杯 → 把剩余 2 升倒入 3 升杯
再次装满 5 升杯 → 向 3 升杯倒 1 升直到装满
5 升杯中剩 4 升
```

面试时重点是清楚描述每一步的状态变化。

---

### 37. 100 扇门

**核心思路：** 第 `k` 扇门只会在轮数是 `k` 的因数时被切换。通常因数成对出现，因此切换偶数次后关闭；只有完全平方数具有奇数个因数。

```text
最终打开：1²、2²、3²……10²
即 1、4、9、16、25、36、49、64、81、100
```

---

### 38. 3 点 30 分时针与分针的夹角

```text
分针：30 × 6° = 180°
时针：3 × 30° + 30 × 0.5° = 105°
夹角：|180° - 105°| = 75°
```

关键点：时针每分钟继续移动 `0.5°`，不是停在数字 `3` 上。

---

### 39. 三刀最多把蛋糕切成多少块

需要先确认蛋糕被看作二维圆饼，还是三维立体蛋糕。

- 二维平面中三条直线最多切成 `7` 块。
- 三维蛋糕中三个平面最多切成 `8` 块。

二维新增第 `n` 刀最多穿过之前所有切线，新增 `n` 块：

```text
最多块数 = 1 + n(n + 1) / 2
```

---

### 40. 两个鸡蛋与 100 层楼

**核心思路：** 让每次第一个鸡蛋碎掉后，剩余最大尝试次数相同。

```text
第一次上升 k 层
第二次上升 k - 1 层
第三次上升 k - 2 层……

k + (k - 1) + ... + 1 >= 100
```

最小的 `k` 是 `14`。第一次从第 `14` 层测试，之后依次增加 `13、12、11...` 层。第一个鸡蛋碎后，用第二个鸡蛋从上一个安全楼层逐层测试。

最坏情况下最多尝试 `14` 次。
