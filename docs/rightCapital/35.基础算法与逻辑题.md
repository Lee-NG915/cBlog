# 二面基础算法与逻辑题速记

> 面试反馈：题目偏基础算法，不难，主要考察数学和逻辑思维。  
> 本文只记录核心思路、伪代码或简短 ES6 写法，不展开完整实现。

---

## 一、答题时的固定表达

1. 先确认输入、输出、数据范围和异常情况。
2. 先说最直观的方案，再说明能否优化。
3. 写代码前用一个例子手动推演。
4. 主动说明时间复杂度和空间复杂度。
5. 最后检查空输入、重复值、负数、溢出和边界下标。

```text
确认题意 → 暴力解法 → 找重复计算或额外空间 → 优化 → 示例验证 → 边界检查
```

## 二、数学与数字处理

### 1. 判断质数 ⭐

**题目：** 输入正整数 `n`，判断它是不是质数。

**核心思路：**

- 小于 `2` 不是质数。
- 如果 `n` 有大于 `sqrt(n)` 的因数，一定同时存在一个小于 `sqrt(n)` 的配对因数。
- 因此只需要检查到 `i * i <= n`。

```js
if (n < 2) return false;
for (let i = 2; i * i <= n; i++) {
  if (n % i === 0) return false;
}
return true;
```

时间复杂度：`O(√n)`；空间复杂度：`O(1)`。

---

### 2. 最大公约数与最小公倍数 ⭐

**核心思路：** 使用欧几里得算法，`gcd(a, b) = gcd(b, a % b)`。

```js
const gcd = (a, b) => {
  while (b !== 0) [a, b] = [b, a % b];
  return Math.abs(a);
};

const lcm = (a, b) => Math.abs((a / gcd(a, b)) * b);
```

先除后乘可以降低中间结果溢出的风险。

时间复杂度：`O(log(min(a, b)))`。

---

### 3. 整数反转

**核心思路：** 每次用 `% 10` 取最后一位，再用整数除法删除最后一位。

1. 使用“当前数字除以 `10` 的余数”取得最后一位。
2. 将“已有反转结果乘以 `10`”，再加上最后一位。
3. 当前数字除以 `10` 并取整，相当于删除最后一位。
4. 重复以上步骤，直到当前数字变成 `0`。

负数可以先保存符号，最后恢复。返回前检查结果是否超出题目规定的整数范围。

---

### 4. 不转字符串判断回文数 ⭐

**核心思路：** 只反转数字的后一半，避免完整反转产生溢出。

1. 负数不是回文数；末尾为 `0` 且自身不为 `0` 的数字也不是回文数。
2. 准备一个变量保存“已经反转的后一半”。
3. 当原数字仍大于反转部分时，把原数字最后一位移到反转部分。
4. 偶数位数字：原数字应该等于反转部分。
5. 奇数位数字：忽略反转部分的中间一位后，两边应该相等。

---

### 5. 数字不断求各位之和

**基础思路：** 循环拆分数字，直到结果小于 `10`。

**数学优化：** 使用数字根。

```js
const digitalRoot = n => (n === 0 ? 0 : 1 + ((n - 1) % 9));
```

原因：十进制下 `10 ≡ 1 (mod 9)`，所以一个数与它的各位和模 `9` 同余。

---

### 6. 阶乘末尾有多少个零

**核心思路：** 一个零来自一个因子 `10 = 2 × 5`。阶乘中因子 `2` 更多，因此只需要统计因子 `5`。

```js
let count = 0;
for (let divisor = 5; divisor <= n; divisor *= 5) {
  count += Math.floor(n / divisor);
}
```

必须继续统计 `25、125...`，因为这些数字包含多个因子 `5`。

---

### 7. 不使用 Math.sqrt 求整数平方根 ⭐

**核心思路：** 在 `[0, n]` 中二分查找满足 `mid² <= n` 的最大整数。

1. 把搜索范围设为 `0～n`，并准备一个变量记录当前合法答案。
2. 计算中间值。
3. 如果“中间值小于等于 `n / 中间值`”，说明中间值的平方没有超过 `n`：记录它，并继续搜索右半区间。
4. 否则继续搜索左半区间。
5. 搜索结束后，最后一次记录的合法值就是整数平方根。

使用 `mid <= n / mid` 可以避免 `mid * mid` 溢出。

时间复杂度：`O(log n)`。

---

### 8. 快乐数

**核心思路：** 不断计算各位数字的平方和。结果只有两种：到达 `1`，或者进入循环。

```js
const seen = new Set();
while (n !== 1 && !seen.has(n)) {
  seen.add(n);
  n = sumOfSquaredDigits(n);
}
return n === 1;
```

空间优化可以把数字变化看成链表，使用快慢指针检测循环。

## 三、数组与基础逻辑

### 9. 两数之和 ⭐

**核心思路：** 遍历时使用 `Map` 保存已经出现的数字及其下标。

```js
const seen = new Map();
for (let i = 0; i < nums.length; i++) {
  const targetValue = target - nums[i];
  if (seen.has(targetValue)) return [seen.get(targetValue), i];
  seen.set(nums[i], i);
}
```

时间复杂度：`O(n)`；空间复杂度：`O(n)`。

---

### 10. 找出 0～n 中缺失的数字 ⭐

**求和方案：**

```js
const expected = (n * (n + 1)) / 2;
return expected - nums.reduce((sum, value) => sum + value, 0);
```

**异或方案：**

1. 准备完整序列 `0～n`。
2. 把完整序列和原数组中的所有数字放在一起异或。
3. 原数组中已有的数字会在完整序列中再出现一次。
4. 因为相同数字异或等于 `0`，它们会两两抵消。
5. 唯一没有配对的数字，就是缺失数字。

例如原数组是 `[3, 0, 1]`，完整序列应该是 `[0, 1, 2, 3]`：

```text
(0 ^ 0) ^ (1 ^ 1) ^ (3 ^ 3) ^ 2 = 2
```

ES6 写法：

```js
const findMissingNumber = nums => {
  let result = nums.length;

  for (let index = 0; index < nums.length; index++) {
    result ^= index;
    result ^= nums[index];
  }

  return result;
};
```

初始值放入 `nums.length`，是因为数组下标只覆盖 `0～n-1`，还需要补上完整序列中的 `n`。异或方案不需要担心求和溢出，额外空间为 `O(1)`。

---

### 11. 只出现一次的数字 ⭐

**核心思路：** `a ^ a = 0`，`a ^ 0 = a`，异或满足交换律。

```js
return nums.reduce((result, value) => result ^ value, 0);
```

适用前提：除一个数字外，其他数字都恰好出现两次。

时间复杂度：`O(n)`；空间复杂度：`O(1)`。

---

### 12. 原地移动零到数组末尾 ⭐

**核心思路：** 双指针。`write` 指向下一个非零数字应该写入的位置。

1. 准备一个“写入位置”指针，初始指向数组开头。
2. 从左到右读取数组。
3. 遇到非零元素，就把它写到“写入位置”，然后将写入位置向后移动。
4. 遍历完成后，把写入位置之后的元素全部改成 `0`。

保留了非零元素的相对顺序。时间 `O(n)`，空间 `O(1)`。

---

### 13. 合并两个有序数组 ⭐

**核心思路：** 两个指针分别指向数组开头，每次取较小值。

1. 分别为两个数组准备一个读取指针。
2. 比较两个指针指向的元素，把较小值放入结果，并移动对应指针。
3. 当其中一个数组读取完成后，把另一个数组的剩余元素直接追加到结果。

如果第一个数组尾部预留了空间，可以从两个数组末尾开始写，避免覆盖未读取的数据。

时间复杂度：`O(m + n)`。

---

### 14. 不排序找第二大值

**核心思路：** 一次遍历维护 `largest` 和 `second`，并忽略与最大值重复的元素。

1. 准备“当前最大值”和“当前第二大值”。
2. 如果新数字大于当前最大值：原最大值降为第二大值，新数字成为最大值。
3. 如果新数字小于最大值但大于第二大值：只更新第二大值。
4. 如果题目求不同元素的第二大值，则忽略与最大值相等的数字。

需要先确认题目要的是“第二大的不同值”，还是排序后第二个位置的值。

---

### 15. 多数元素

**核心思路：** Boyer-Moore 投票算法。不同数字相互抵消，超过一半的数字最终一定留下。

```js
let candidate;
let count = 0;
for (const value of nums) {
  if (count === 0) candidate = value;
  count += value === candidate ? 1 : -1;
}
return candidate;
```

如果题目不保证多数元素存在，需要再遍历一次验证出现次数。

时间 `O(n)`，空间 `O(1)`。

---

### 16. 两个数组的交集

**不保留重复：**

```js
const right = new Set(nums2);
return [...new Set(nums1)].filter(value => right.has(value));
```

**保留重复次数：** 使用 `Map` 记录一个数组中每个数字剩余的出现次数，匹配一次后减一。

## 四、字符串与括号

### 17. 有效括号 ⭐

**核心思路：** 遇到左括号入栈，遇到右括号时检查是否与栈顶配对。

```js
const pairs = new Map([
  [')', '('],
  [']', '['],
  ['}', '{'],
]);
```

1. 遇到左括号时，将它压入栈中。
2. 遇到右括号时，取出栈顶左括号，并检查两者是否匹配。
3. 如果没有可取出的左括号，或者类型不匹配，立即返回不合法。
4. 遍历结束后，栈必须为空。

时间 `O(n)`；空间 `O(n)`。

---

### 18. 第一个只出现一次的字符

**核心思路：** 第一次遍历计数，第二次按原顺序找计数为 `1` 的字符。

```js
const count = new Map();
for (const char of str) count.set(char, (count.get(char) ?? 0) + 1);
for (const char of str) if (count.get(char) === 1) return char;
```

`for...of` 按 Unicode Code Point 遍历，比按字符串下标更适合处理部分 Unicode 字符；完整 Grapheme Cluster 仍需要 `Intl.Segmenter`。

---

### 19. 判断字母异位词 ⭐

**排序方案：**

```js
const normalize = value => [...value].sort().join('');
return normalize(a) === normalize(b);
```

时间复杂度约为 `O(n log n)`。

**计数方案：** 用 `Map` 对第一个字符串加一，对第二个字符串减一，最后全部为零。时间 `O(n)`，空间取决于字符集大小。

---

### 20. 最长公共前缀

**核心思路：** 把第一个字符串作为前缀，依次与后续字符串比较；不匹配时不断缩短前缀。

1. 先把第一个字符串作为候选公共前缀。
2. 依次检查后续字符串是否以该前缀开头。
3. 如果不匹配，就不断删除候选前缀的最后一个字符。
4. 当前缀为空或所有字符串都匹配时结束。

也可以纵向逐列比较所有字符串的同一位置。

---

### 21. 压缩字符串

**核心思路：** 使用游标统计连续相同字符的长度。

1. 从当前起点向后寻找第一个不同字符。
2. 两个位置之差就是当前字符连续出现的次数。
3. 把“字符和次数”写入结果。
4. 将起点移动到下一个不同字符，继续统计。

如果题目要求“压缩后更长则返回原字符串”，生成结果后比较长度即可。

---

### 22. 解码字符串

**题目示例：** `3[a2[c]] → accaccacc`

**核心思路：** 使用两个栈分别保存进入 `[` 前的重复次数和已有字符串。

1. 遇到数字时，累积出完整的重复次数，例如把 `12` 识别为十二次。
2. 遇到 `[` 时，把重复次数和之前已经生成的字符串分别入栈，然后重置当前状态。
3. 遇到普通字母时，将它追加到当前字符串。
4. 遇到 `]` 时，取出重复次数和上一层字符串，把当前字符串重复后拼接回上一层。

嵌套结构必须按照后进先出的顺序处理。

## 五、查找与区间

### 23. 二分查找 ⭐

```js
let left = 0;
let right = nums.length - 1;

while (left <= right) {
  const mid = left + Math.floor((right - left) / 2);
  if (nums[mid] === target) return mid;
  if (nums[mid] < target) left = mid + 1;
  else right = mid - 1;
}
return -1;
```

关键是始终保持搜索区间定义一致，例如上面使用闭区间 `[left, right]`。

---

### 24. 有序数组的插入位置 ⭐

**核心思路：** 查找第一个“大于等于目标值”的位置，也就是 Lower Bound。

1. 使用左闭右开区间，左边界指向可能的答案，右边界指向搜索范围之外。
2. 如果中间值小于目标值，答案只可能在中间位置右侧，因此移动左边界。
3. 否则中间位置本身可能就是答案，因此把右边界移动到中间位置。
4. 当左右边界相遇时，该位置就是第一个大于等于目标值的位置。

即使目标值不存在，`left` 最终也是正确插入位置。

---

### 25. 不修改数组找重复数字

**条件：** 长度为 `n + 1`，元素范围为 `1～n`，只有一个重复数字。

**核心思路：** 把“下标指向对应数字”看成链表。重复数字会形成环，使用 Floyd 快慢指针：

1. 慢指针每次走一步，快指针每次走两步，直到它们在环内相遇。
2. 把慢指针放回起点，快指针留在相遇位置。
3. 两个指针都改为每次走一步。
4. 再次相遇的位置就是环入口，也就是重复数字。

时间 `O(n)`；空间 `O(1)`；不修改原数组。

---

### 26. 合并重叠区间

**核心思路：**

1. 按区间起点排序。
2. 当前区间起点小于等于上一个结果区间的终点时合并。
3. 否则开启一个新区间。

```js
intervals.sort((a, b) => a[0] - b[0]);
```

排序占主要成本，时间复杂度为 `O(n log n)`。

---

### 27. 最大连续子数组和 ⭐

**核心思路：** Kadane 算法。当前位置的最佳结果，要么从当前数字重新开始，要么接在前面的连续子数组后面。

```js
let current = nums[0];
let best = nums[0];
for (let i = 1; i < nums.length; i++) {
  current = Math.max(nums[i], current + nums[i]);
  best = Math.max(best, current);
}
```

不要把初始值设为 `0`，否则无法正确处理全部为负数的数组。

时间 `O(n)`；空间 `O(1)`。

## 六、递归、回溯与组合

### 28. 斐波那契数列 ⭐

**问题：** 直接递归会重复计算相同子问题，时间复杂度接近 `O(2ⁿ)`。

**迭代方案：**

```js
let previous = 0;
let current = 1;
for (let i = 0; i < n; i++) {
  [previous, current] = [current, previous + current];
}
return previous;
```

时间 `O(n)`；空间 `O(1)`。

---

### 29. 爬楼梯 ⭐

**核心思路：** 到达第 `n` 级的最后一步，只可能来自 `n - 1` 或 `n - 2`：

```text
ways(n) = ways(n - 1) + ways(n - 2)
```

本质上是斐波那契数列。使用两个变量滚动保存前两项即可。

---

### 30. 数组扁平化

**ES6 方案：**

```js
array.flat(Infinity);
```

**递归思路：**

1. 依次读取数组中的每个元素。
2. 如果当前元素仍然是数组，就递归展开它。
3. 如果不是数组，就直接放入最终结果。
4. 如果题目指定展开深度，每进入一层递归就把剩余深度减一，减到零后停止展开。

指定深度时，每次递归将 `depth - 1`，到 `0` 后停止展开。

---

### 31. 全排列

**核心思路：** 回溯。每一层选择一个尚未使用的数字，递归完成后撤销选择。

1. 准备一条“当前排列路径”和一组“已经使用的数字”。
2. 如果路径长度等于原数组长度，保存当前路径的副本。
3. 否则依次尝试每个尚未使用的数字。
4. 选择数字后，将它加入路径并标记为已使用，然后继续递归。
5. 递归返回后，移除刚才的数字并取消标记，再尝试下一个选择。

如果输入存在重复数字，需要先排序，并在同一层跳过重复选择。

---

### 32. 求所有子集

**迭代思路：** 初始只有空集。每遇到一个数字，把它加入现有每个子集，生成一批新子集。

```js
let result = [[]];
for (const value of nums) {
  result = [...result, ...result.map(group => [...group, value])];
}
```

共有 `2ⁿ` 个子集，因此时间和结果空间至少都是 `O(2ⁿ)`。

### 34. 八个球找出较重的球 ⭐

**核心思路：** 第一次把球分为 `3、3、2`。

```text
称 3 对 3：
平衡 → 重球在剩余 2 个中，再称一次
不平衡 → 重球在较重的 3 个中，取其中 2 个互称
```

最少两次。每次天平称重有三种结果，因此两次最多区分 `3² = 9` 种情况。

### 35. 两根燃烧不均匀的绳子计算 45 分钟

```text
绳 A 在 30 分钟后烧完
此时点燃绳 B 的另一端
绳 B 剩余部分再过 15 分钟烧完
合计 45 分钟
```

虽然燃烧速度不均匀，但两端同时燃烧会把总时间减半。

### 38. 3 点 30 分时针与分针的夹角

```text
分针：30 × 6° = 180°
时针：3 × 30° + 30 × 0.5° = 105°
夹角：|180° - 105°| = 75°
```

关键点：时针每分钟继续移动 `0.5°`，不是停在数字 `3` 上。

### 39. 三刀最多把蛋糕切成多少块

需要先确认蛋糕被看作二维圆饼，还是三维立体蛋糕。

- 二维平面中三条直线最多切成 `7` 块。
- 三维蛋糕中三个平面最多切成 `8` 块。

二维新增第 `n` 刀最多穿过之前所有切线，新增 `n` 块：

```text
最多块数 = 1 + n(n + 1) / 2
```

### 40. 两个鸡蛋与 100 层楼

**核心思路：** 让每次第一个鸡蛋碎掉后，剩余最大尝试次数相同。

```text
第一次上升 k 层
第二次上升 k - 1 层
第三次上升 k - 2 层……

k + (k - 1) + ... + 1 >= 100
```

最小的 `k` 是 `14`。第一次从第 `14` 层测试，之后依次增加 `13、12、11...` 层。第一个鸡蛋碎后，用第二个鸡蛋从上一个安全楼层逐层测试。

最坏情况下最多尝试 `14` 次。
