# 本地验收版实现与验证记录

日期：2026-09-23。版本：本地基础验收版 v0.1。分支：`codex/knowledge-platform-design`。

本轮按用户最新要求交付本地版本，不创建 Cloudflare 资源，不部署线上，不配置或启用付费产品。原 `apps/web`、`apps/admin`、`content/`、`data/blog.db` 保留，新工作台在 `apps/knowledge`，API 在 `apps/api`，本地数据在忽略提交的 `.knowledge/`。

## 2. 与最终目标设计的差异（明确未交付）

1. **真正的向量语义检索、模型生成的引用问答未接入。** 当前自然语言输入通过全文与有限同义词匹配；不等同于 embedding 语义搜索。问答入口明确显示未连接，API 返回 AI_UNAVAILABLE，未伪造生成答案。没有调用 Cloudflare AI 或外部模型，也没有发送笔记到模型服务。
2. 当前是 **Vite/React + Base UI 的独立本地外壳**；未切换旧 Next/Fumadocs 正式阅读端。公开演练由本机 remark 静态构建，不是 GitHub Actions 生产发布。公开静态页中的 Mermaid 暂保留源码，交互图表在登录后的阅读端可用。
3. 编辑器采用可保真源码模式与预览，未宣称 Milkdown 可视化编辑已通过 IME/格式往返门槛。
4. GitHub OAuth 路由已实现但无真实凭证，未做真实身份联调。**本机一键进入仅由 loopback 开发适配器注册，Worker 不含该入口。** 不能将本地适配器对外暴露。
5. 云端 D1/KV 写入、CPU 额度、GitHub Actions 发布、资源配额降级、Vectorize、线上回滚未实测；Wrangler 中 ID 仍为占位值。现有 Cloudflare 只读连接不代表这些已通过。
6. 尚未验证 iOS/Android 真机 IME、辅助阅读器、20 题 AI 质量集、10 MiB 浏览器压力与全量 75 条验收。因此不能标记 G0–G6 全通过或生产就绪。
7. 附件 GC、修订自动压缩、生产审计指标和自动备份调度尚未开放。本地历史当前完整保留，数据量增长后须先落地容量维护再云迁移。
8. 私人索引目前在浏览器内存进行全文匹配，尚未迁入 Web Worker/服务端大规模索引。初始 90 篇可用，不承诺无限增长。

这些差异是当前模块交付边界，不替换用户的最终需求。后续应继续完成目标设计的未实现模块。
