# 出海 DTC 市场营销团队 · 各模块工作拆解

---

## 一、团队整体结构

出海 DTC 营销团队按"渠道 + 支撑"两条线组织：

**渠道线（获客与转化）**

| 模块 | 定位 |
| --- | --- |
| 官网销售（站点运营） | 官网 GMV 第一责任人，促销机制与页面运营 |
| 广告（Paid Ads） | Meta + Google 付费投放 |
| SEO | 自然搜索流量与内容建设 |
| EDM | 邮件营销（Campaign + 自动化 Flow） |
| Organic Social | 自有社媒账号内容运营 |
| Affiliate | 联盟营销渠道 |
| PR / KOL | 媒体公关与达人合作 |

**支撑线**

| 模块 | 定位 |
| --- | --- |
| 官网开发 | 业务需求承接、重点项目、工程整合、视觉审计 |
| 每周检查 | 竞对监控、活动日历同步 |
| 官网内容 / 官网提效 | 页面内容质量与站点效率优化（专项） |

团队节奏：周会周报制，每周按模块汇报「达成情况 → 现状 → 风险 → 待办/下周 To Do」四段式；围绕月度目标（如月度销售目标、H2 目标）拆解。

---

## 二、官网销售 / 站点运营（DTC Site Operations）

### 职责

- 官网整体销售目标（月度销售、大促目标）的达成与复盘
- 促销活动机制设计与落地：满赠、秒杀、Bundle、抽奖、延保、折扣码（Coupon）等
- 活动页 / Landing Page / 集合页 / PDP（产品详情页）的内容与结构运营
- 站内转化路径优化：announcement bar 倒计时、跳转板块、页面意图调整
- 活动日历的制定与跨渠道同步
- 大促复盘（如劳动节大促复盘：现状 → 结论 → 产品表现 → 机制表现）

### 关注的指标

- 销售额 / 销量（pcs、$GMV）、全站占比
- 分 Campaign 销量与效率对比（哪个 campaign 效率最高）
- Coupon 使用率、订单占比
- 老品 vs 新品的销售贡献与增量
- 页面流量 → 转化（订阅 / 购买）的漏斗数据
- Blog 等流量页面的转化率、订阅率

### 用到的工具 / 平台

- Shopify（站点与订单口径）
- 自建数据看板（如 DTC commerce dashboard、周报数据看板）
- 协作平台的任务 / 文档（待办与协同）

### 典型工作方法

- **Campaign 机制分阶段设计**：如会员日大促拆三段——满 $200 赠礼袋 → 48h 秒杀 → Top Picks 精选，每段配独立 H1/H2/H3 文案与 CTA
- **UTM 规范管理**：每个活动固定 campaign name ，保证归因
- **页面意图分层**：识别流量页面用户属性（潜在新客 vs 购买意图），将页面目标从"主转化"调整为"主订阅"
- **大促期间主 Sale 页切换为集合页为主**，复杂机制才用独立活动页，简化常规促销的设计与开发成本
- **新品节奏运营**：预售首销→ 开售物料调整（保留订阅抽奖、赠品调整、取消延保和 Buy2 折扣、加倒计时）

## 三、广告（Paid Advertising）

### 职责

- Meta 与 Google 两大平台的投放策略、预算分配与日常优化
- 按产品系列（新品 / 老品 / 全品购物广告）分 Campaign 管理
- 素材（Creative）与关键词（Keyword）维度的效果分析与迭代
- 与 PR / KOL / 运营节点协同投放节奏（不在内容发布分散期盲目加曝光）
- 对 SEO 表现好的 blog 进行加投（每关键词配 2 个链接、3 个关键词）

### 关注的指标

- 花费（Spend）vs GMV 的趋势与波动
- 中间漏斗：CTR（点击率）、FQ（频次，Frequency）、ATC（加购）、Checkout（结账）
- 分平台 / 分 Campaign / 分 URL / 分素材 / 分关键词的颗粒度数据
- ROAS / 广告销售额（活动结束后权益期对比）

### 用到的工具 / 平台

- Meta Ads（Facebook / Instagram 投放）
- Google Ads：按漏斗分层使用——Demand Gen（触达）→ PMax（考虑）→ Search / Shopping（转化）

### 典型工作方法

- **漏斗分层投放**（Google 侧示例）：触达层用 Demand Gen 投新品 landing page / 首页；Consideration 层用 PMax；转化层用 Search / Shopping 覆盖全产品
- **素材生命周期管理**：CTR 持续下降即判断素材老化，需产出新内容；FQ 达到 4 说明人群已饱和、上层拓圈节奏混乱
- **跨渠道归因意识**：趋势图增幅节点对照 EDM 激活、SEO 发布，识别非广告因素的波动
- **节奏协同原则**：PR / KOL 发布节奏分散时，广告不做过多曝光引流；新品需先保证 PR 和 KOL 的持续产出，再划预算配合

## 四、SEO

### 职责

- 关键词规划与内容排期（月度关键词表输出给供应商）
- Blog 内容生产管理：内部撰写 + 供应商外包（如 9 月 50 篇 = 供应商 35 篇 + 内部 15 篇，含预算管理）
- 已有高流量文章的持续优化（如蜂鸟迁徙类文章）
- 商业页面（首页 / 产品页 / 集合页）自然流量提升
- Pillar Page（主题支柱页）建设：gift 主题、迁徙主题等
- SEO 配图 / 封面设计资源协调（内部设计 + 外包）
- 大促 SEO 策略（黑五策略）、跨渠道协同（建议社媒 YouTube 主打关键词、EDM 插入好文章主题）

### 关注的指标

- Organic Search 流量及全站占比、目标达成率
- Blog 流量占 Organic 的比例
- Organic Keyword 数量及排名分布（如 363 → 1100，新增排名集中在 11–50）
- 单篇文章排名变化（如 hummingbird migration map 从第 4 提升至第 2）
- 商业页面 vs Blog 页面的自然流量结构比（商业页合计仅 45.3% 被视为风险）

### 用到的工具 / 平台

- 关键词 / 排名监控工具（Ahrefs、SEMrush 类）
- 供应商 / 外包写手体系
- 内部图库（SEO 配图统一上传）

### 典型工作方法

- **热点 + 常青双线**：结合节点热点发文（Grandparents Day），同时培育常青 blog 降低季节性波动
- **头部文章保卫**：持续更新头部季节性文章保持排名，并增加相关 Blog 内链
- **内容 → 转化闭环**：流量文章内增加新品与促销跳转板块；对转化好的 blog 反哺广告投放
- **风险识别**：流量依赖单篇季节性头部文章 = 结构脆弱，需主动对冲

## 五、EDM（邮件营销）

### 职责

- 常规 Campaign 邮件：促销、新品上新、教育内容、月度回顾、大促预热 / 正式 / Last Call
- 自动化 Flow 搭建与优化：Welcome、浏览未购、加购未购、弃单（Abandoned Cart）、购买后培育系列
- 用户分层与发送频率管理：活跃人群优先、不活跃进 Win-back、减少无差别群发
- A/B 测试：标题、内容角度（利益导向 vs 场景导向）
- 邮件平台迁移：Klaviyo → Brevo 的灰度切换与预热（IP warming）
- 8–12 月 EDM 排期规划（与 DTC 节点、SEO 内容协同）

### 关注的指标

- 送达率（目标 ~99%）、退订率（0.84% 即亮黄灯预警）
- 打开率 / 点击率 / 点击后购买转化
- 归因订单数、归因销售额、Flow 转化率
- 发送量 / 进入 Flow 人数（漏斗源头健康度）

### 用到的工具 / 平台

- Klaviyo（原平台）
- Brevo（新平台，含 Welcome Flow 接客、IP 预热节奏表）
- Shopify（销售归因口径）

### 典型工作方法

- **IP 预热标准化节奏**：逐日放量 1,000 → 1,500 → 2,300 → 3,300 → 冷却核账 → 8,100 活跃用户拆批发送 → 验收切换，全程监控送达率与退订率
- **未打开用户的再触达**：不做"原邮件重发"，改为换标题 / 预览文案 / 首屏 banner 的 Last Chance 邮件，只发近期活跃未打开人群
- **购后培育序列设计**：下单 1 天（感谢 + 安装联网 + 客服入口）→ 10 天（看鸟体验优化）→ 20 天（使用关怀 + 配件推荐）
- **诊断逻辑**：发送量降 25% + 打开人数降 46.5% 但点击率仅降 1.34% → 问题在"进 Flow 的人少了 + 标题打开弱"，不在内容
- **内容洞察**：同题材下"迁徙"比"选购"点击率高约 65% —— 季节性、地域相关性内容更激发兴趣

## 六、Organic Social（自有社媒运营）

### 职责

- 多平台日常内容发布：FB / Instagram / YouTube（含 Shorts），每周约 10 条视频
- 内容类型组合：趣味互动向（约 70%）+ 产品卡点视频（约 30%）+ 科普图文 + 促销 / 上新海报
- FB 小组 / 社区运营：PR 文章进小组分享、用户评价图分发
- UGC / KOC 长期共创：以配件、Plus 权益、Affiliate 佣金、官号曝光作激励
- 评论区引流：FB/ins/YT 评论区引导主页 Bio 链接 + ins Story 链接贴纸
- 新品节奏：TVC 上 YT 带 tag、Shorts 导流长视频、社媒产品露出统一聚焦主推新品
- 8–12 月社媒排期规划（对标竞对打法制定）

### 关注的指标

- 发布量（周 10 条）
- 自然流播放量 / 爆款（如单条 16k+、28k+、74k+ views）
- 互动量（评论数，如互动海报 40+ 评论）
- Bio 链接 / Story 贴纸点击（引流官网）

### 典型工作方法

- **内容配比公式**：30% 爆款复刻 + 50% 新素材主题测试 + 20% 爆款广告内容测试
- **竞对打法对标融合**：头部竞品 A 的"新品揭晓—早鸟权益—开售—达人测评"快速转化 × 竞品 B 的"功能拆解、社区参与"延长热度 → 前期集中爆发 + 后期真实内容共创
- **新品内容叙事顺序**：揭晓是什么 → 证明为什么更好 → 回答是否适合我 → 展示别人使用效果 → 制造购买时效，避免持续重复新品海报

## 七、Affiliate（联盟营销）

### 职责

- 联盟平台运营与月度结算（佣金 + 合同续费付款）
- 联盟客（Partner）拓展：建联信触达头部联盟客、验证不同类型联盟客（Cashback / Deal 类 / 内容类）的合作可行性
- 联盟客质量监控：识别可疑出单（流量来源存疑、推广方式与 properties 不一致）
- 大促节点激励方案：平台集中激励、首单激励、主推产品加佣、Newsletter 节奏
- 联盟物料管理：Banner 素材设计 Brief、Campaign 素材上传
- Affiliate Landing Page 项目推进（官网联盟招募页）
- 联盟体系诊断与策略规划（Affiliate Dashboard 搭建）

### 关注的指标

- Clicks（点击）、Actions / 转化数、Revenue、GMV 环比
- CVR（转化率）、AOV（客单价）、CPC
- 活跃 Partner 数量、出单 Partner 数量及集中度（Top2 占比从 62.2% 降至 44.6% 视为结构优化）
- 新增 Partner 的贡献占比（点击 / 订单 / 销售额）

### 用到的工具 / 平台

- impact.com（主联盟平台）
- Levanta（亚马逊 + 沃尔玛渠道联盟）
- UTM 链接检查
- 自建 Affiliate Dashboard（诊断看板）

### 典型工作方法

- **Partner 结构去集中化**：监控头部依赖度，主动扩充出单来源（1 个出单 → 7 个出单 Partner）
- **大促运营三板斧**：提前一周 Newsletter 预告活动 + 未出单联盟客首单 $30 激励 + 主推新品加佣
- **低门槛测试机制**：新联盟客以资源置换或纳入节点推广（万圣节）先试单
- **适配性判断**：品牌词主动搜索量不足时，coupon 类 Deal 联盟客不是当前阶段最优合作类型
- **无效流量排查**：如德国站带来 37% 点击零转化 → 归因于地域与 DTC 承接不匹配

## 八、PR / KOL（公关与达人营销）

### KOL 侧职责

- KOL 排期管理：定档、寄样、发布节点跟踪（与新品、大促节奏对齐）
- 类型分层：YouTube dedicated（长视频深度测评）、YouTube integration、Shorts 达人
- 预算管理（如总定档 19 位、总花费 $7,300）
- 发布效果监测与补救：播放量低于账号均播时排查原因（caption 缺品类大词、hashtag 堆砌品牌词）、沟通重发 / 重新编辑
- Agency 协同：取消合作后的补位 KOL list 沟通

### PR 侧职责

- 媒体 review 投放：agency 渠道（Forbes、PCMag、The Verge、垂类媒体）+ inhouse 渠道（垂类站点）
- 通稿发布（美通社 PR Newswire）
- 奖项申报（PopSci、Family Award Choices，含收款账户等流程跟进）
- 媒体 pitch 拓展：新垂类媒体建联、约定 earned review 时间

### 关注的指标

- KOL 发布视频 views vs 账号均播（相对表现，而非绝对值）
- 定档数量、总花费、各平台发布节奏
- 媒体发布数量（月度目标，如 9 月 6 篇 review）
- PR / KOL 产出节奏的持续性与集中度（供广告侧判断加投时机）

### 用到的工具 / 平台

- KOL 管理表（站外推广排期表，含权限隔离）
- Agency 外包合作
- 美通社（PR Newswire）通稿渠道

### 典型工作方法

- **内容诊断颗粒度**：视频扑街归因到 caption 缺流量品类词、品牌 + 产品 hashtag 过多 → 重编文案后与 YouTube integration 同节点重发
- **双轨媒体策略**：agency 打大众权威媒体（Forbes / PCMag / The Verge），inhouse 打垂类媒体（鸟类观察类站点），兼顾权威背书与精准人群

## 九、官网开发（站点技术支撑）

### 职责

- 业务需求承接与开发量预估（官网开发需求预估表）
- 重点项目推进
- 网站视觉审计：梳理字体、颜色、布局、间距、交互、按钮规范，形成可视化评审页面（现状 / 建议 / 待确认）
- 多品牌工程整合：两个品牌站点整合为 monorepo，统一开发工作流、构建检查、交付记录，同时保留品牌代码与环境隔离

### 工作方法

- 规范先行：优先评审高频组件及近期需求涉及的规则，确认后逐步应用
- 小需求先验证再推广统一工作流，完善差异合并与配置保留

## 十、跨模块机制（团队运营层）

1. **周报节奏**：每周固定四段式汇报（达成 / 现状 / 风险 / 待办），数据看板 + 待办双轨
2. **活动日历驱动**：所有渠道围绕统一活动日历（新品上市、劳动节、会员日大促、黑五网一、万圣节）排期，共用 campaign name 和 landing page
3. **每周检查**：竞对监控、月度活动日历同步、官网内容与提效专项检查
4. **跨渠道协同规则**：
   - SEO 好文章 → 插入 EDM 排期、广告加投
   - PR / KOL 节奏 → 决定广告投放强度
   - SEO 关键词洞察 → 指导社媒 YouTube 选题
   - 社媒内容 ← 站外内容测试方向 ← PDP 单点素材优化互相验证
